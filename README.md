# Laura & Breno — 19.12.2026

Site responsivo de casamento com cores bordô e dourado, abertura em vídeo, convite PDF, contagem regressiva, informações e área futura de confirmação de presença.

## Arquivos
- `index.html`: página principal
- `styles.css`: visual e responsividade
- `script.js`: abertura e contagem regressiva
- `assets/abertura.mp4`: vídeo a adicionar
- `assets/convite.pdf`: convite a adicionar

Os arquivos MP4 e PDF ainda não foram incluídos. Envie-os para a pasta `assets/` com os nomes acima. Local, horário e confirmação de presença são campos provisórios. O horário das 16h da contagem regressiva também é provisório.

## Publicação
No GitHub: Settings → Pages → Deploy from a branch → main / (root). Depois, o endereço será https://jamillydanielle.github.io/laura-breno/ .
